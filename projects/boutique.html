쇼핑몰 · 03

명품잡화 쇼핑몰

패션잡화 전문 쇼핑몰의 상품 탐색부터 주문·결제까지 편리한 온라인 쇼핑 환경 구축

기간
2026년 08월 ~ 2026년 09월
맡은 역할
디자인 · 프론트엔드 · 백엔드 (프리랜서)
사용 기술
  • HTML/CSS
  • JavaScript
  • PHP
  • MySQL
  • 영카트
  • PG 결제 (KG이니시스·토스페이먼츠)
명품잡화 쇼핑몰 / LIVE WEB

미리보기 안을 스크롤하면 페이지 전체를 볼 수 있습니다. 오른쪽 위 아이콘으로 태블릿·모바일 화면으로 바꿀 수 있습니다.

01

개요

PHP·MySQL과 영카트를 기반으로 패션잡화 쇼핑몰을 구축한 프로젝트입니다. 상품·브랜드 카테고리, 상세페이지, 장바구니, 위시리스트, 회원·주문관리, 게시판, 관리자 기능을 개발했고, PC·모바일 반응형 UI를 적용해 상품 관리부터 주문까지 쇼핑몰의 전체 사용자 흐름을 구현했습니다.

02

담당 작업

디자인 · 화면

  • 쇼핑몰 화면 디자인
  • PC·모바일 반응형 UI 적용

상품 탐색

  • 상품·브랜드 카테고리 개발
  • 상품 상세페이지 개발
  • 위시리스트 기능 개발

주문 · 결제

  • 장바구니 기능 개발
  • 주문 흐름 구현
  • PG 결제 연동 (KG이니시스·토스페이먼츠 등)

회원 · 관리자

  • 회원·주문관리 기능 개발
  • 게시판 기능 개발
  • 상품·주문 관리자 기능 개발

03

문제와 해결

문제

명품잡화는 브랜드와 카테고리가 많고 상품 정보가 풍부해서, PC와 모바일 어디서나 상품 탐색부터 결제까지 흐름이 끊기지 않게 만드는 것이 과제였습니다.

해결

영카트를 커스텀해 브랜드·카테고리 탐색 구조를 만들고, 반응형 UI로 PC와 모바일 화면을 함께 설계했습니다. KG이니시스·토스페이먼츠 등 PG 결제를 연동해 장바구니부터 결제까지 한 흐름으로 이어지게 했습니다.

04

성과

상품 탐색부터 장바구니·주문·결제, 관리자의 상품·주문관리까지 쇼핑몰 전체 흐름을 2개월 동안 디자인부터 개발까지 직접 맡아 구축했습니다.
